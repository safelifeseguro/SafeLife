# 🛡️ SafeLife

Sistema inteligente para **gestão de seguros de vida**.

O **SafeLife** é uma aplicação desenvolvida para gerenciar apólices de seguro de vida de forma simples, organizada e eficiente. O sistema permite controlar **clientes, apólices e beneficiários**, garantindo que todas as informações relacionadas ao seguro estejam centralizadas e facilmente acessíveis.

O objetivo principal do projeto é oferecer **segurança, organização e agilidade** no gerenciamento de seguros de vida individuais.

---

# 📌 Sobre o projeto

O **SafeLife** foi criado pela **TwoStack**, uma empresa de desenvolvimento de software focada na criação de soluções digitais eficientes, modernas e escaláveis.

Este projeto representa a base de um sistema de **gestão de seguros**, que poderá evoluir com novas funcionalidades ao longo do tempo.

---

# 🗄️ Estrutura do Banco de Dados

O sistema é composto por três tabelas principais:

### 👤 Cliente
Armazena as informações das pessoas seguradas.

### 📄 Apólice
Registra os dados do seguro contratado pelo cliente.

### 👨‍👩‍👧 Beneficiários
Define quem receberá o valor do seguro em caso de sinistro.

---

# ⚙️ Funcionalidades atuais

Atualmente, o sistema permite:

## 👤 Cliente
- Cadastrar novos clientes  
- Atualizar informações de clientes  
- Remover clientes  
- Buscar todos os clientes  
- Buscar cliente por **CPF**

## 📄 Apólice
- Criar nova apólice  
- Atualizar apólice  
- Remover apólice  
- Buscar todas as apólices  
- Buscar apólice por **ID**

## 👨‍👩‍👧 Beneficiários
- Cadastrar beneficiários  
- Atualizar beneficiários  
- Remover beneficiários  
- Buscar todos os beneficiários  
- Buscar beneficiário por **ID da apólice**  
- Buscar beneficiário por **ID do beneficiário**  
- Buscar beneficiário por **nome**

# ⚙️ Instalação

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/SafeLife.git
cd SafeLife
```

Instale as dependências:
```bash
npm install
```

Execute o projeto:
```bash
npm run start:dev
```
